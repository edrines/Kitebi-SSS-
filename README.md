# Kitebi SSS

Kitebi SSS is a modern school information system for student registration, search, staff management, academic results, attendance and fees.

## Included in this release

- Responsive dashboard
- Student registration and search
- Student directory
- Staff records
- Academic result entry
- Attendance entry
- Fee/payment entry
- Browser-local persistence with `localStorage`
- GitHub Pages deployment workflow

## Important deployment note

This release is a fully functional browser-based application for demonstration and single-device use. Records are stored in the browser on the device being used; they are **not yet a shared school database**. A production deployment with multiple users, secure authentication, permissions, backups and shared records requires a backend/database.

## Run

Open `index.html` or use the GitHub Pages site generated by the repository's Pages workflow.
